## Notes

- The Python client bounds every row at about 135-138k messages/s over 64 tunnels; the
  numbers that matter are the proxies' CPU per message: nginx 3.75 us, agensio 3.80 us,
  parity (each message crosses the proxy twice, so about 1.9 us per hop, the cost of one
  read and one write on each side).
- Caddy failed every tunnel: its reverse proxy tunnels `Upgrade: websocket` only, and the
  echo uses a custom upgrade token so that no framing is needed. Not a Caddy defect; a
  real WebSocket load generator would be needed for a Caddy row.
