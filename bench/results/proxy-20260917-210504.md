## Notes (Node.js origin, both proxies forwarding the same fields)

- Node alone is the ceiling at about 156-160k req/s, so this row compares what each proxy
  makes the origin do. With both proxies sending Host, X-Forwarded-For and
  X-Forwarded-Proto (agensio's defaults; the bench nginx now sets X-Forwarded-Proto too,
  as production nginx configurations do) they tie: nginx 155-157k, agensio 153-158k, run
  to run within noise, agensio using 5-6 % less CPU of its own (5.8 vs 6.1-6.2 us).
- The earlier 3-7 % gap (`proxy-20260917-204812.md`, `-205017.md`) was entirely fields
  the origin parsed: a redundant `Connection: keep-alive` (dropped) and `X-Forwarded-Host`
  next to an unchanged Host (now sent only when Host is rewritten or a proxy in front set
  it). With forwarding off entirely (`proxy-20260917-210320.md`) agensio reaches 164-168k
  against nginx's 159-164k, which bounds what any proxy can gain here: bytes.
