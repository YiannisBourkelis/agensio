# HTTP/3 streamed answers, measured, 2026-11-08

What a streamed proxy answer (`proxy = { buffering = false }`) costs over HTTP/3 now that it
streams (0.1.0-alpha.142, docs/design-http3.md 7.3), against the same answer buffered and against
HTTP/2. The base cannot take part: over HTTP/3 it reset every streamed answer.

- machine: AMD Ryzen 9 9900X, Debian 13, Linux 6.12.113+deb13-amd64, in agensio-devbox (h2load with
  QUIC from /opt/nghttp2/bin)
- binary: f8594a01 plus the three HTTP/3 commits of 0.1.0-alpha.142 (the reset fix, the streaming,
  compression in pieces), build/agensio, one worker; the benchmark upstream build/agensio_upstream
- command: `docker run --rm --init --ulimit nofile=65536:65536 -v $PWD:$PWD -w $PWD -e HOME=/home/dev
  --user 1000:1000 agensio-devbox:latest streamed-bench.sh build/agensio OUT.md RAWDIR 5` (the script
  below); h2load -c CONNS -m 1 -t 4, a request count from a 1 s probe times 5; CPU us/req = the
  process's CPU over the answered requests; two rounds. Raw h2load output of the second round in
  raw/h3-streamed-20261108-233933/.

Streamed over HTTP/3 costs about what streamed over HTTP/2 costs on the small answer (`/json` 9.5 to
10.2 against 9.4 us) and less on the larger ones (`/big`, 100 KB, 33.8 to 36.4 against 43.5;
`/pages`, 512 KB, 115 to 119 against 166 to 167). Against the same answer buffered over HTTP/3 it
costs 7 to 11 % more on `/json` and 25 to 32 % on `/big`: the copy into the send blocks and a read
per 16 KB piece (HTTP/2's streamed path costs 17 to 48 % more than its buffered one on the same rows).

**The buffered `/pages` rows over HTTP/3 (300 and 82 req/s) are not the rate:** the run took 140 and
423 s for a request count a 1 s probe ran at 8,400 req/s, so connections stalled until the end. The
same row bounded by time (`h2load -D 10`, alternated) gives base and new alike, 5,233 / 8,118 against
4,916 / 8,102 req/s, and the base binary (f8594a01) stalls on the request count too (40,000 requests
not done in 150 s). A stall of large buffered answers over HTTP/3 older than this series, to be
investigated on its own; the streamed path does not show it (8,402 and 8,690 req/s, whole run).

The script:

```bash
#!/usr/bin/env bash
# A streamed proxy answer over HTTP/3 against the same answer buffered, and against HTTP/2, one
# agensio worker in front of the benchmark upstream (build/agensio_upstream): server CPU
# microseconds per request (the process's CPU over h2load's requests). Runs in agensio-devbox
# (h2load with QUIC under /opt/nghttp2/bin). usage: streamed-bench.sh BINARY OUT.md RAWDIR [SECONDS]
set -euo pipefail
BIN=$1 OUT=$2 RAW=$3 DUR=${4:-5}
ROOT=$(pwd)
H2LOAD=/opt/nghttp2/bin/h2load
mkdir -p "$RAW" bench/tmp
export LC_NUMERIC=C
ulimit -n 65536 2>/dev/null || true
CONF=bench/tmp/h3-streamed-bench.toml
cat > "$CONF" <<EOF
[server]
workers = 1
protocols = ["h2", "h1", "h3"]
max_requests_per_connection = 1000000
pid_file = "$ROOT/bench/tmp/h3-streamed-bench.pid"
[log]
access = "off"
[[site]]
server_name = ["*"]
listen = ["127.0.0.1:18461"]
tls = { cert = "$ROOT/bench/certs/cert.pem", key = "$ROOT/bench/certs/key.pem" }
upstream = "http://127.0.0.1:9100"
app = "proxy"
[[site]]
server_name = ["*"]
listen = ["127.0.0.1:18462"]
tls = { cert = "$ROOT/bench/certs/cert.pem", key = "$ROOT/bench/certs/key.pem" }
upstream = "http://127.0.0.1:9100"
app = "proxy"
proxy = { buffering = false }
EOF
build/agensio_upstream > "$RAW/upstream.log" 2>&1 & UP=$!
"$BIN" -c "$CONF" > "$RAW/agensio.log" 2>&1 & SRV=$!
trap 'kill $SRV $UP 2>/dev/null; wait 2>/dev/null' EXIT
for _ in $(seq 1 50); do curl -sk -o /dev/null https://127.0.0.1:18462/json && break; sleep 0.1; done
HZ=$(getconf CLK_TCK)
cpu() { awk '{print $14+$15}' /proc/$SRV/stat; }
{
  echo "| proto | site | path | conns | req/s | CPU us/req | ok/total |"
  echo "|---|---|---|---|---|---|---|"
} > "$OUT"
row() {  # proto site port path conns
  local proto=$1 site=$2 port=$3 path=$4 conns=$5 alpn
  alpn=$proto; local url="https://127.0.0.1:$port$path"
  local probe; probe=$($H2LOAD --alpn-list=$alpn -D 1 -c "$conns" -m 1 -t 4 "$url" 2>/dev/null | awk '/^finished in/{print $4}')
  local n=$(( ${probe%%.*} * DUR )); [ "$n" -lt 1000 ] && n=1000
  local f="$RAW/$proto-$site-${path//\//_}-$conns.txt"
  local c0; c0=$(cpu)
  $H2LOAD --alpn-list=$alpn -n "$n" -c "$conns" -m 1 -t 4 "$url" > "$f" 2>&1
  local c1; c1=$(cpu)
  local done_n ok rps
  done_n=$(awk '/^requests:/{print $2}' "$f"); ok=$(awk '/^status codes:/{print $3}' "$f")
  rps=$(awk '/^finished in/{print $4}' "$f")
  local us; us=$(awk -v c=$((c1 - c0)) -v hz="$HZ" -v n="$ok" 'BEGIN{ if (n > 0) printf "%.2f", c / hz * 1e6 / n; else print "-" }')
  echo "| $proto | $site | $path | $conns | $rps | $us | $ok/$done_n |" >> "$OUT"
  echo "$proto $site $path $conns: $rps req/s, $us us/req, $ok/$done_n"
}
for round in 1 2; do
  for path_conns in "/json 64" "/big 64" "/pages 8"; do
    set -- $path_conns
    for proto in h3 h2; do
      row $proto buffered 18461 "$1" "$2"
      row $proto streamed 18462 "$1" "$2"
    done
  done
done
```
