Machine: AMD Ryzen 9 9900X, Debian 13 (kernel 6.12.107), the `agensio-devbox-perf`
container; commit c682b84 plus the working tree of phase I's first slice (uncommitted at
the time of the run). Command: `BIN=bench/tmp/h3bin/agensio bench/httparena/profile-h3.sh` (raw output in
`raw/h3-profile-20260924/profile.txt` for the first run of the slice and `profile-final.txt`
for the tree as committed, after the three corrections of the day; the table is the final run). The load is the arena's own
`h2load` over QUIC (the `h2load-h3:local` image built from its
`docker/h2load-h3.Dockerfile`: nghttp2 1.69 with ngtcp2 and quictls), `--alpn-list=h3

answered by the arena handler (agensio) or a two-byte static file (nginx; the arena's
nginx entry answers the sum from a module, which the devbox's nginx does not have, so the
nginx row is the closest work its static path does).

What it says: the transport is a small part of the request (packet building 2.7 %, the
AEAD 3.8 %, the kernel 4.7 %); the request's fields cost the most, and the first lever
is QPACK's dynamic table on the decoding side, then the encoder's memo for content-type,
the stream lookup by slot instead of by scan, and the `Stream::reset` cost that HTTP/2
shares. The datagram count says our answers are about 57 bytes on the wire against
nginx's 25 (its dynamic-table head): the encoder side of the same table halves the
packets.
