# Large answers over HTTP/3 on a request count, before and after the GSO message limit, 2026-11-09

The stall of 512 KB answers over HTTP/3 reported with 0.1.0-alpha.142
(`h3-streamed-20261108-233933.md`): a GSO message of 65,508 to 65,535 bytes was refused by the
kernel (EMSGSIZE, IPv4 takes 65,507) and its datagrams lost, and on loopback the end of a 512 KB
answer was sent again in the same two datagrams (47,104 and about 18,400 bytes) and refused again.
The fix caps a message at 65,507 bytes and sends the MTU probe in a message of its own.

- machine: AMD Ryzen 9 9900X, Debian 13, Linux 6.12.113+deb13-amd64, in agensio-devbox (h2load with QUIC
  from /opt/nghttp2/bin)
- base: v0.1.0-alpha.142 (096f7b7e), the binary `bench/ab.sh` built in bench/tmp/ab/096f7b7e/build
  with build/'s options; new: build/agensio, 096f7b7e plus the fix (src/quic/udp.hpp,
  src/quic/connection.hpp); one worker each, alternated, two rounds
- command: `docker run --rm --init --ulimit nofile=65536:65536 -v $PWD:$PWD -w $PWD -e HOME=/home/dev
  --user 1000:1000 agensio-devbox:latest burst-bench.sh bench/tmp/ab/096f7b7e/build/agensio
  build/agensio OUT.md bench/results/raw/h3-burst-20261109-195626 20000 2` (the script below); per row
  `h2load --alpn-list=h3 -n 20000 -c 8 -m 1 -t 4`, cut by `timeout 60`; raw h2load output in
  raw/h3-burst-20261109-195626/
- files: 128 KB and 512 KB of text (cached in memory), 2 MB of random bytes (above max_file_size 1 MB:
  a descriptor entry, read in file windows); /pages is the benchmark upstream's 512 KB page, proxied
  and buffered in memory

Before the fix the 512 KB file and the 512 KB proxied answer never finished 20,000 requests in 60 s,
and the 2 MB file did not in the first round (the second finished, with one request at 2.69 s). After
it every row finishes, the slowest request 53 to 59 ms. The 128 KB row finishes on both; its rate
swings between runs (32.8k to 50.0k req/s on the new side alone), so this table shows the stall, not
a cost: that is the A/B's (ab-20261109-173923.md).

The script:

```bash
#!/usr/bin/env bash
# Large answers over HTTP/3 with a request count (h2load -n), the base binary against the new one,
# alternated: a 128 KB, a 512 KB and a 2 MB static file (the first two cached in memory, the third a
# descriptor entry read in file windows) and a 512 KB proxied answer buffered in memory (the
# benchmark upstream's /pages). One worker, 8 connections, one stream each; a run that does not
# finish in 60 s is cut and shows as such. Runs in agensio-devbox (h2load with QUIC under
# /opt/nghttp2/bin). usage: burst-bench.sh BASE_BIN NEW_BIN OUT.md RAWDIR [N] [ROUNDS]
set -uo pipefail
BASE=$1 NEW=$2 OUT=$3 RAW=$4 N=${5:-20000} ROUNDS=${6:-2}
ROOT=$(pwd)
H2LOAD=/opt/nghttp2/bin/h2load
export LC_NUMERIC=C
ulimit -n 65536 2>/dev/null || true
T=bench/tmp/h3-burst; W=$T/www; mkdir -p "$W" "$RAW"
[ -f "$W/p128.html" ] || head -c 131072 /dev/urandom | base64 -w 100 | head -c 131072 > "$W/p128.html"
[ -f "$W/p512.html" ] || head -c 524288 /dev/urandom | base64 -w 100 | head -c 524288 > "$W/p512.html"
[ -f "$W/p2m.bin" ] || head -c 2097152 /dev/urandom > "$W/p2m.bin"
CONF=$T/burst.toml
cat > "$CONF" <<EOF
[server]
workers = 1
protocols = ["h2", "h1", "h3"]
max_requests_per_connection = 1000000
pid_file = "$ROOT/$T/burst.pid"
[log]
access = "off"
[cache]
max_file_size = 1048576
[[site]]
server_name = ["*"]
listen = ["127.0.0.1:18471"]
tls = { cert = "$ROOT/bench/certs/cert.pem", key = "$ROOT/bench/certs/key.pem" }
root = "$ROOT/$W"
[[site.location]]
path = "/pages"
match = "exact"
upstream = "http://127.0.0.1:9100"
EOF
build/agensio_upstream > "$RAW/upstream.log" 2>&1 & UP=$!
SRV=
trap 'kill $SRV $UP 2>/dev/null; wait 2>/dev/null' EXIT
echo "| round | binary | path | seconds | req/s | done/total | request max |" > "$OUT"
echo "|---|---|---|---|---|---|---|" >> "$OUT"
for round in $(seq 1 "$ROUNDS"); do
  for side in base new; do
    bin=$BASE; [ $side = new ] && bin=$NEW
    "$bin" -c "$CONF" > "$RAW/agensio-$side-$round.log" 2>&1 & SRV=$!
    for _ in $(seq 1 50); do curl -sk -o /dev/null https://127.0.0.1:18471/p128.html && break; sleep 0.1; done
    for p in /p128.html /p512.html /pages /p2m.bin; do
      f="$RAW/$round-$side-${p//\//_}.txt"
      t0=$(date +%s.%N)
      timeout 60 $H2LOAD --alpn-list=h3 -n "$N" -c 8 -m 1 -t 4 "https://127.0.0.1:18471$p" > "$f" 2>&1
      rc=$?
      t1=$(date +%s.%N)
      secs=$(awk -v a="$t0" -v b="$t1" 'BEGIN{printf "%.1f", b - a}')
      rps=$(awk '/^finished in/{print $4}' "$f"); [ -n "$rps" ] || rps="cut at 60 s"
      dn=$(awk '/^requests:/{print $6}' "$f"); [ -n "$dn" ] || dn="?"
      mx=$(awk '/^request +:/{print $4}' "$f")
      echo "| $round | $side | $p | $secs | $rps | $dn/$N | ${mx:--} |" >> "$OUT"
      echo "$round $side $p: rc=$rc ${secs}s $rps req/s, $dn/$N, max $mx"
    done
    kill $SRV 2>/dev/null; wait $SRV 2>/dev/null; SRV=
    sleep 1
  done
done
```
